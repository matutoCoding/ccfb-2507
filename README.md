# 浮染坊 · 大理石纹纸设计系统（Ebru Marbling Studio）

面向手工精装书与老书修复装帧工作室的浏览器内大理石纹纸（浮染 / Ebru）设计系统。
TypeScript + 原生 WebGL2（手写 GLSL 着色器，无 three.js），React 18 + Vite。

## 核心设计：工序即数据，渲染走反向追踪

系统不存任何位图。每个操作（滴墨、梳齿）都是一条 JSON 工序，出图时对每个输出像素
**逆序穿过所有操作反推初始颜色**。因此同一套工序在任意分辨率下重算，600dpi 边界
依然是连续数学函数，天然锐利、可无限放大。

### 面积守恒滴墨

每滴墨是严格面积守恒（雅可比行列式 = 1）的径向不可压变换：

- 盘内 ρ ≤ r：被新墨覆盖；
- 盘外 ρ > r：ρ′ = √(ρ² + r²)，旧色环被向外推，总面积不增不减。

几百滴叠加也不会"糊成一片"——没有任何网格扩散或数值耗散。

### 梳齿变形

梳齿是沿齿方向、垂直距离不变的位移场（保证面积守恒）：

```
u′ = u + s·exp(−v²/w²)·bump(t)
```

逆映射对单调函数做固定 20 次二分求逆，约束 |s| ≤ w 保证单调可逆。
单齿梳、多齿梳（齿距/齿数可调）、波浪梳（振幅/波长/相位）、来回次数（反向 pass 强度取反）
在录制时由 `expandComb` 纯函数确定性展开为直线齿痕，GPU 与 CPU 共用同一展开结果。

### 确定性保证

- 渲染路径严禁 `Math.random` / `Date.now`，所有随机量走 mulberry32 + 整数哈希；
- GLSL 哈希与 TS 哈希位级对应（全程 uint / `>>>0` 无符号语义），有锁定值单元测试；
- 同一份工序在任何机器、任何时间重放，同分辨率下**逐字节一致**（自测页实测 0 差异）；
- GPU 与 CPU 参考渲染器逐公式对应，内部像素偏差 ≤1 色阶（抗锯齿边界单列亚像素差）。

## 颜料与纸面模型

- **扩散性**：决定墨滴铺展半径 `r × (0.55 + 1.35×diffusion)`；
- **胆汁（ox gall）**：用量越高，色环外缘白圈越明显；
- **吸墨晕边**：纤维纹理 + 颗粒 + 环缘羽化，全部基于物理毫米坐标（与分辨率解耦）；
- **金粉/银粉**：金属 BRDF（方向光 + 视角倾角控制的各向异性高光 + 金粉颗粒闪烁），
  拖动"观察倾角"滑块可看斜视角反光变化。

## 印刷模型（近似，非 ICC 替代）

- Beer-Lambert 乘性吸光：`R = R_paper·exp(−Σ αᵢ·墨量ᵢ)`，墨层独立、多色叠印自然变暗；
- UCR 灰成分替代 + 近黑区黑墨直通；
- 色域检测：分色再正向叠印，与目标色算 ΔE2000，阈值可调；
- PNG 内嵌 pHYs 物理分辨率块，印刷软件可直接识别 dpi。
- **正式制版请接打印机/纸张的 ICC profile**，本模型只用于印前预检。

## 高分辨率导出与性能

- 全宽水平带逐带离屏渲染 + 回读，瓦片级操作包围盒裁剪（`culling.ts`），
  每带只上传相关操作；
- PNG 手写 CRC32/块结构，zlib deflate 走浏览器原生 `CompressionStream`，流式编码；
- A3 600dpi ≈ 7000 万像素，目标 20 秒内（自测页显示实测耗时，取决于 GPU）。

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm test           # vitest 单元测试（51 个，含数学/色彩/PNG/裁剪/配方）
npm run build      # tsc 类型检查 + 生产构建
```

## 目录结构

```
src/
  engine/        纯 TS 核心：反向追踪、颜料、色彩科学、配方、裁剪、老纸生成、CPU 渲染
  gl/            WebGL2 渲染器与 GLSL 着色器（与 engine 逐公式对应）
  export/        高分辨率导出、流式 PNG 编码
  ui/            React 页面与组件
test/            vitest 单元测试
```

## 已知边界

- 简化胶印模型是工艺预检近似，不能替代真实 ICC 色彩管理；
- 滴墨上限 512、齿痕段上限 4096、单滴最多 8 色环（超出在 UI 拦截）；
- 跨分辨率的严格 ≤1 色阶口径只适用于内部像素，色环抗锯齿边界存在连续函数固有的亚像素差异。
